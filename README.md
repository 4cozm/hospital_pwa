# 병동 치료 스케줄 (PWA 목업)

시간대별 치료 이송 일정을 한 화면에서 확인하는 정적 PWA. 서버 없음, 데이터는 `localStorage`에만 저장.

- 병실: 1201~1219 → "1~19호". 1~11호 일반 4인, 12~18호 특실 1인, 19호 특실 2인 (`app.js` 상단 `ROOMS`)
- 이동수단: 혼자 / 워커 / 베드 / 휠체어. 워커·베드·휠체어는 보조가 필요해 `이송 → 복귀 요청 받음 → 복귀 완료` 3단계(복귀 요청 받음 = 누가 나에게 "모셔오세요"라고 했는지 적어 두는 표시), 혼자만 `확인` 1단계 (`MOB`의 `escort`)
- 배포: GitHub Pages (Settings → Pages → `main` / root). 모든 경로가 상대경로

## 치료 일정 일괄 입력 (사진 → AI → 앱)

일정표 사진은 외부 AI(ChatGPT, Claude 등)가 텍스트로 바꾸고, 앱은 그 텍스트를 **검증한 뒤** 한 번에 넣는다.

1. 치료일정 탭 → `일괄 입력` → `AI 변환 규칙 · 형식 보기` → `AI 규칙 복사`
   (규칙 원본은 `ai-prompt.txt`. 등록한 시술 이름·별칭이 자동으로 채워진다)
2. AI 대화에 규칙을 붙여넣고 일정표 사진을 보낸다
3. AI가 준 텍스트를 앱에 붙여넣거나 `.txt` 파일로 불러온다
4. 미리보기에서 오류·확인 필요 행을 고친 뒤 `가져오기`

형식 (한 줄 = 한 행): `호실|시간|성명|이동수단|처방|메모`

```
날짜=11-13
1|09:00|홍길동|휠체어|도수+PT@09:40|
6|09:40|이영희|베드|PT|bed 확인
# 취소: 8호 09:00 박민수 (퇴원)
행수=2
```

검증: 열 개수·호실(1~19)·시간(24시간제)·이동수단 4종·시술 등록 여부·환자 등록 여부(호실+이름)·중복(목록 안/오늘 기존)·날짜·행수·`?`(AI 불확실 표시).
오류 행은 절대 가져오지 않고, 애매한 행(이름 유사, 호실 불일치, 1~8시 시간 등)은 직접 체크해야 들어간다. 오류 행은 미리보기에서 환자·이동수단·시술을 직접 골라 해결한다.
직접 고른 시술은 별칭으로 기억해서 다음부터 자동 인식한다.

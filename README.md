# 병동 치료 스케줄 (PWA 목업)

시간대별 치료 이송 일정을 한 화면에서 확인하는 정적 PWA. 서버 없음, 데이터는 `localStorage`에만 저장.

- 병실: 1201~1219 → "1~19호". 1~11호 일반 4인, 12~18호 특실 1인, 19호 특실 2인 (`app.js` 상단 `ROOMS`에서 수정)
- 이동 방식: 혼자 / 휠체어 / 베드. 휠체어·베드는 `모시러 감 → 치료 완료·귀실`, 혼자는 `확인 완료` 한 번
- 배포: GitHub Pages (Settings → Pages → 브랜치/루트). 모든 경로가 상대경로라 하위 경로에서도 동작
- 파일 수정 후에는 `sw.js`의 `VERSION`을 올릴 것
